# 📚 Lire — AI Powered Book Reader & Listener

Lire is a modern AI-powered book reading and listening platform that transforms PDFs into immersive reading and audiobook experiences.

Users can upload PDF books, read them inside a beautiful minimal interface, generate AI narration audio, and follow along with synchronized transcripts — all inside a cinematic web experience.

# ⚙️ Installation

## 1️⃣ Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/lire.git
```

---

## 2️⃣ Navigate Into Project

```bash
cd lire
```

---

# 🔧 Backend Setup

## Install Dependencies

```bash
cd backend
npm install
```

---

## Create Environment File

Create a `.env` file inside the backend folder.

```env
PORT=5000
MONGODB_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
OPENAI_API_KEY=your_api_key
```

---

## Start Backend Server

```bash
npm run dev
```

Server will run on:

```bash
http://localhost:5000
```

---

# 💻 Frontend Setup

## Install Dependencies

```bash
cd frontend
npm install
```

---

## Start Frontend

```bash
npm start
```

Frontend will run on:

```bash
http://localhost:3000
```

# 🧠 How It Works

## Step 1 — Upload PDF
User uploads a PDF book.

## Step 2 — PDF Processing
Backend extracts:
- Text
- Metadata
- Cover image

## Step 3 — AI Audio Generation
The extracted text is converted into narration audio.

## Step 4 — Transcript Sync
Generated transcript is displayed alongside the audio player.

## Step 5 — Reading Experience
Users can:
- Read
- Listen
- Navigate pages
- Track progress
