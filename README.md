# 📚 Lire — AI Powered Book Reader & Listener

Lire is an AI-powered book reading platform that transforms PDFs into interactive reading and audiobook experiences.

Users can upload PDF books, read them in a modern interface, generate AI narration audio, and follow along with transcripts.

---

# ✨ Features

- 📖 Upload and read PDF books
- 🎧 AI-generated audiobook narration
- 📝 Transcript generation
- 🖼 Dynamic PDF cover extraction
- 🔐 User authentication system
- 🎨 Modern responsive UI
- ⚡ Fast and smooth experience

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/Amatrasu66/Lire-book-reader-app.git
```

---

## Navigate Into Project

```bash
cd Lire-book-reader-app
```

---

# 🔧 Backend Setup

```bash
cd Lire/backend
npm install
npm run dev
```

Backend runs on:

```bash
http://localhost:5000
```

---

# 💻 Frontend Setup

```bash
cd ../frontend
npm install
npm start
```

Frontend runs on:

```bash
http://localhost:3000
```

---

# 🔑 Environment Variables

Create a `.env` file inside the backend folder:

```env
PORT=5000
MONGODB_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
OPENAI_API_KEY=your_api_key
```
